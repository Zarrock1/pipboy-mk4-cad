# Pip-Boy 3000 Mk IV — CAD и файлы печати

- `cad/zapwizard_unfinished/` — полный архив "Pip-Boy Unfinished Version" ZapWizard (Joshua Driggs), Google Drive, дек. 2017.
  Исходник: https://drive.google.com/drive/folders/1NlcHtdtjH62fnaz1pvxRJu8AqO-tezmg
- `print/stl/` — все STL одной папкой, см. `print/README.md`.
- `docs/PROJECT_NOTES.md` — заметки по треду RPF, электронике, плану.
- Код интерфейса: https://github.com/Zarrock1/pypboy

Лицензия материалов ZapWizard: CC BY-NC-SA (`cad/zapwizard_unfinished/Cc-by-nc-sa.png`).

`cad/zapwizard_unfinished/Render/Keyshot Render, Pip-Boy.zip` разрезан на части (лимит GitHub 100 МБ). Склеить:

```bash
cat "Keyshot Render, Pip-Boy.zip.part"* > "Keyshot Render, Pip-Boy.zip"
```

Windows (cmd): `copy /b "Keyshot Render, Pip-Boy.zip.part00"+"Keyshot Render, Pip-Boy.zip.part01" "Keyshot Render, Pip-Boy.zip"`
