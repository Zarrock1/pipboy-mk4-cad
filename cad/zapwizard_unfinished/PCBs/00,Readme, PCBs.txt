Notes for PCBs:

The .ASM files are assembly models. These files can only be opened in SolidEdge (ST7 or higher).
The .PAR files are master CAD files. These files can only be opened in SolidEdge (ST7 or higher).
The .DXF files are 2D files that give the dimensions of the boards.

These parts are 3D models of the intended PCB layout. No actual PCB designs have been completed at the time of this writing. (2017)
