Notes for DragonBoard:

The .ASM file is an assembly.
The .PAR files are master CAD files. These files can only be opened in SolidEdge (ST7 or higher).

All these parts were imported from commercially available electrical models.

About the Dragonboard 410c. It was selected due to its ability to run Android or Linux, as well as having enough horsepower to handle all the other GUI tasks.
No development on the 410c has actually taken place at the time of this writing. (2017)
