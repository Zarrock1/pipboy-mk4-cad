Notes for Custom Other:

The .PAR files are master CAD files. These files can only be opened in SolidEdge (ST7 or higher).
The .DXF files are 2D files that give the dimensions of the parts.
The artwork for some parts can be found in the artwork folder.

The thickness of the parts can be extracted by measuring the 3D model in a CAD program.
Most of these parts can be laser cut from acrylic.
