Note for Holoetape Schematic:

The .SCH file is a Eagle CAD schematic.

I drew the schematic, but never built or tested it. The idea is to use a timer to generate a
variable digital signal that can be changed by the potentiometer and read by a IR sensor.
A second timer encodes the signal onto a carrier wave that is then decoded by the IR receiver.
This works the same way as many IR remote controls.
