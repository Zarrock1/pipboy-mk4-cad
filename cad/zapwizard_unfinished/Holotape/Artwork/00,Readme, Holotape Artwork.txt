Note for Holoetape Artwork files:

The .CDR files are Corel Draw X8 master files.
The .PSD files are Photoshop CS5 master files.
The .SVG file are vector artwork and can be opened by most browsers and vector art programs.
The .PNG files are bitmap outputs, and used as textures in renderings.
If printing out to paper, use the master files to generate higher DPI images.
