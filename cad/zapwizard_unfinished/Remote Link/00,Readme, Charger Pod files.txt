Note for Charger Pod files:

The Charger Pod can be built as its own seperate prop, so the files are included in their own folder.

The .PAR, .PSM, .ASM files are master CAD files. These files can only be opened in SolidEdge (ST7 or higher).
Each part contains Metadata with details and notes as needed. The meta data can only be read inside SolidEdge.

The .STEP files are transferable 3D CAD files that can be opened by more professional CAD software.
These have all the detail of the master files. Think of them as a sort of "Vector art" version, compared to the "Bitmap" quality of an STL file.

The .STL files are raw outputs. Theses files are designed to be printed on a SLS 3D printer using Nylon or Polymide.
The .STL files are NOT designed to be printed on a FDM 3D printer. If you don't know what a FDM 3D printer actually is, and you have a 3D printer...well then you have a FDM 3D printer.
No support will be given to users attempting to print the files on a FDM, SLA, or any non-SLS 3D printer.

If you don't/can't print the parts youself, then you can purchase the 3D parts from my store on Shapeways.com.
As this design is unfinished, there are no guarentees granted by ZapWizard. Shapeways however does have a return policy.
Visit: www.3DPipBoy.com to order

The .CDR files are Corel Draw X8 master files.
The .PSD files are Photoshop CS5 master files.
The .SVG file are vector artwork and can be opened by most browsers and vector art programs.
The .PNG files are bitmap outputs, and used as textures in renderings.
the .BIP file can be opened in Keyshot 5
If printing out to paper, use the master files to generate higher DPI images.
