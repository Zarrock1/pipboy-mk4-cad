# Файлы для печати

`stl/` — все STL из архива ZapWizard "Pip-Boy Unfinished Version" (копии из `../cad/zapwizard_unfinished/`).
Имя файла: `<папка-источник>__<имя>.stl`.

- Рассчитано на SLS (нейлон). На FDM — с потерей деталей, нужна шлифовка (слова автора).
- Описание каждой детали и материал — в одноимённом `.txt` рядом с оригиналом в `cad/zapwizard_unfinished/<папка>/`.
- Это версия декабря 2017. Изменения 2018–2021 (радио 1:9, магнит в гололенте, шарнир-слипринг и т.д.) сюда не входят.
